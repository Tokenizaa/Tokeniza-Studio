# Architecture Decision Records (ADRs)

ADRs registram decisões técnicas, contexto, alternativas, consequências e estado. Uma decisão aprovada não deve ser alterada silenciosamente: registre uma nova ADR que a substitua.

## Estados
- **Proposed:** em discussão.
- **Accepted:** aprovada.
- **Rejected:** avaliada e rejeitada.
- **Superseded:** substituída por outra decisão.
